# 놓치지마수업 — 홈페이지 게시용 인수 자료

> 이 문서는 프로그램을 만든 채팅에서, 워드프레스 글을 쓰는 채팅으로 넘기는 자료입니다.
> **확인하지 못한 기능은 글에 쓰지 마세요.** 9번 「확인한 것 / 못 한 것」을 먼저 읽으세요.
> 이 프로그램은 웹앱이 아니라 **윈도우 설치 프로그램**입니다. `webapp-post-writer` 스킬은 웹앱(URL을 열어 캡처)을
> 전제로 하므로 그대로 쓸 수 없습니다. 카테고리·글 구조는 정쌤에게 확인하세요(웹도구 카테고리 57이 맞는지 포함).

작성: 2026-10-14 · 버전 1.0.0 · 제작: 공부하는정쌤(충북 중학교 수학교사)

---

## 1. 한 줄 소개

컴시간알리미에 등록된 학교의 선생님을 위한 **무료 윈도우 프로그램**. 내 수업이 시작하는 시각에
「1-4 수업입니다」처럼 **화면 한가운데 크게** 띄워 줍니다. 수업을 놓치지 않게 하는 것이 전부인 작은 프로그램입니다.

## 2. 만든 배경 (정쌤 본인의 말투로 쓸 수 있는 사실만)

- 정쌤이 쓰는 교사용 프로그램 「티룸」에 이미 있던 「수업 알림」 기능만 따로 떼어 낸 것입니다.
- 계기: 1교시 수업이 바뀐 것을 모르고 교무실에 있었던 일(티룸 수업 알림을 만든 이유, 2026-09-30).
- 「이것만 필요한 사람들이 있을 것 같아서」 따로 만들어 무료로 배포합니다(정쌤 말).
- 시간표 카드는 보러 가야 보이지만, 알림은 먼저 찾아온다는 점이 핵심입니다.

## 3. 누구에게 맞나

- 컴시간알리미를 쓰는 학교의 교사(학교 이름으로 검색해 고르고, 수업 길이는 40·45·50분 중에서 고릅니다. 개발과 시험은 중학교 시간표로 했습니다).
- 교실·교무실에서 **윈도우 컴퓨터**를 켜 놓고 지내는 선생님.
- 교체·보강이 잦아 오늘 내 수업이 바뀌었는지 놓치기 쉬운 선생님.

## 4. 주요 기능

1. **정시 알림**: 교시 시작 시각에 알림 창이 뜸. 화면 아무 곳이나 누르면 닫힘(창이 선택돼 있으면 엔터·스페이스·Esc로도 닫힘).
   누를 때까지 저절로 닫히지 않음.
2. **바뀐 수업 표시**: 컴시간이 교체·보강으로 표시한 수업이면 알림에 「바뀐 수업」 알약 표시가 붙음.
3. **컴시간 시간표 자동 연동**: 학교를 검색해 고르면 전 학년 전 반 시간표에서 내 수업만 골라 냄.
   시간표는 중학교 30분, 고등학교 40분마다 새로 받아 오고, 못 받으면 마지막에 받은 시간표를 씀.
4. **같은 이름의 선생님 구분**: 컴시간은 이름을 두 글자로 줄여 보여 줘서(정유경 → 정유) 동명이인이 섞일 수 있음.
   같은 이름이 둘 이상이면 사람마다 **대표 수업 하나(과목+반)** 만 보여 주고 「선생님이 수업하시는 건 어느 것인가요?」
   하고 물어서 고른 사람 기준으로 시간표를 만듦. (예: 정미란=수학 1-1, 정미지=과학 1-1, 정미경=수학 1-7 → 세 개 중 선택)
   실제 학교 하나에서 두 글자 이름이 겹치는 경우가 7건이나 나올 만큼 흔한 문제입니다.
5. **교시 시각 설정**: 1교시 시작(8:20~9:00, 5분 단위)과 수업 길이(40/45/50분)를 고르면 쉬는 시간 10분으로 나머지 교시가
   자동으로 채워짐. 점심 등으로 늦게 시작하는 교시는 그 교시의 시각만 고치면 **뒤 교시가 같은 만큼 밀림**
   (몇 곳이든 고칠 수 있음). `1315`처럼 숫자만 쳐도 `13:15`로 바뀜. 교시는 1~9교시.
6. **소리**: 소리 없음 또는 윈도우 기본 소리 7종(차임·딩·알림·화음·알람·벨·팡파르), 내 wav 파일도 가능. 「들어보기」 있음.
7. **글씨체**: 알림 창 글씨체 선택 — 기본(맑은 고딕), 학교안심 은하수·우주·지우개, 프리텐다드.
8. **자동 실행**: 컴퓨터를 켤 때 자동으로 시작(기본 켜짐, 설정에서 끌 수 있음).
9. **트레이 상주**: 화면 오른쪽 아래 알림 영역(시계 옆)의 종 모양 아이콘으로 계속 켜져 있음. 설정 창을 닫아도 꺼지지 않음.
   아이콘 메뉴: 다음 수업 표시 / 설정 열기 / 알림 켜기·끄기 / 테스트 알림 / 시간표 지금 새로 받기 / 종료.
10. **컴시간이 안 될 때**: 설정에서 「컴시간 없이 직접 입력」으로 요일·교시별 「반 과목」을 손으로 넣을 수 있음.
11. **절전 대응**: 절전에서 늦게 깨어나도 시작 시각으로부터 3분 이내면 알림.

## 5. 사용 흐름 (캡처와 함께)

설치 → 처음 실행하면 설정 창이 열리고 4단계를 거칩니다. 마지막 **「완료」가 저장**입니다(저장 단추는 따로 없음).
설정 창을 중간에 X로 닫으면 저장되지 않고, 프로그램은 트레이에 남습니다.

| 단계 | 하는 일 | 캡처 |
|---|---|---|
| 1/4 학교 찾기 | 학교 이름 일부를 검색해 목록에서 선택 | `screenshots/01_school.png` |
| 2/4 내 수업 확인 | 이름 입력 → 컴시간에서 내 수업을 찾아 보여 줌. 같은 이름이 있으면 어느 분인지 물음 | `screenshots/02_same_name.png` |
| 3/4 교시 시작 시각 | 1교시 시작·수업 길이 선택, 점심 뒤 교시만 고침, 교시 추가/빼기 | `screenshots/03_times.png` |
| 4/4 소리와 자동 실행 | 소리·글씨체·자동 실행, 「알림 미리보기」 | `screenshots/04_sound_font.png` |

평소에는 아무것도 할 필요가 없습니다. 수업 시작 시각에 알림이 뜹니다.

## 7. 이런 경우엔 맞지 않습니다 (글에 꼭 넣을 것)

- **컴시간알리미를 쓰지 않는 학교**: 시간표를 가져올 수 없습니다(직접 입력은 가능).
- **나이스(NEIS) 시간표**: 지원하지 않습니다. 나이스는 선생님별 시간표를 주지 않기 때문입니다.
- **윈도우 전용**(64비트). 윈도우 10에서 만들고 시험했습니다. 맥·스마트폰은 안 됩니다.
- **컴퓨터가 꺼져 있거나 프로그램이 꺼져 있으면** 알림이 오지 않습니다.
- 시험·행사 때문에 수업이 없는 날을 자동으로 건너뛰는 기능은 **없습니다**(그날 수업이 시간표에 있으면 알림이 뜹니다).
  (티룸에는 있지만 이 프로그램에는 넣지 않았습니다.)
- 컴시간알리미 쪽 구조가 바뀌면 한동안 시간표를 못 받을 수 있습니다(비공식 방식으로 읽기 때문). 그때는 마지막으로 받은
  시간표나 직접 입력한 시간표를 씁니다.
- 학교가 시간표를 올리지 않았거나 이번 주 시간표가 아직 없으면 알림이 오지 않을 수 있습니다.
  (지난주 시간표를 이번 주 것처럼 알리지는 않습니다.)

## 8. 자주 묻는 질문 (정확한 답)

- **설정은 어디에 저장되나요?** 내 컴퓨터 `%APPDATA%\놓치지마수업\settings.json`에만 저장됩니다. 서버로 보내지 않습니다.
- **인터넷 연결이 필요한가요?** 시간표를 받을 때만 컴시간알리미에 접속합니다. 받아 둔 시간표가 있으면 연결이 없어도 알림은 뜹니다.
- **관리자 권한이 필요한가요?** 필요 없습니다. 내 계정에만 설치됩니다.
- **알림이 안 뜨면?** 트레이 메뉴의 「테스트 알림」으로 모양을 확인하고, 「시간표 지금 새로 받기」를 눌러 보세요.
  교시 시각이 학교 일과표와 맞는지도 확인하세요.
- **끄려면?** 트레이 아이콘 → 「알림 끄기」(잠시 멈춤) 또는 「종료」.
- **지우려면?** 윈도우 설정 → 앱 → 놓치지마수업 → 제거(자동 실행 등록도 함께 지워집니다).
- **학교를 옮기면?** 트레이 → 설정 열기 → 학교를 다시 검색해 「완료」.
- **무료인가요?** 무료입니다.

## 9. 확인한 것 / 못 한 것 (글에 반영할 때 기준)

**직접 시험해 확인한 것**
- 설치 파일 폴더의 실행 파일(exe)이 정해 둔 시각에 알림을 띄우는 것(실제 exe로 시각을 맞춰 확인)
- 알림 창 모양(둥근 모서리, 바뀐 수업 표시, 글씨체 5종), 아무 곳이나 눌러 닫기, 뜬 직후 0.7초 클릭 무시
- 컴시간에서 학교 검색·시간표 받기(실제 학교로 확인), 교사 번호로 동명이인 구분(예시 자료로 확인)
- 설정 4단계 흐름, 교시 시각 자동 계산·밀기, 숫자만 쳐도 시각 변환, 설정 창을 닫아도 프로그램이 살아 있는 것
- 계산 로직 자동 검사 통과

**못 했거나 확인이 덜 된 것 (글에서 단정하지 말 것)**
- **설치 파일로 실제 설치해 본 적 없음**(설치·제거, 제거 시 자동 실행 등록 삭제 포함).
- **트레이 아이콘이 시계 옆에 실제로 뜨는 것**을 눈으로 확인하지 못함(코드는 들어 있고, 실행 중 꺼지지 않는 것은 확인).
- **컴퓨터를 켤 때 자동으로 시작되는 것**을 재부팅으로 확인하지 못함.
- **윈도우 11**, 다른 PC 여러 환경, 학교 PC의 보안 프로그램과의 충돌은 확인하지 못함.
- **초등학교·고등학교** 시간표로는 시험하지 못함(학교 이름으로 수업 길이의 처음 값만 40/45/50분으로 정해 둠).
- 소리가 실제로 나오는 것은 소리 파일 재생 호출까지만 확인(스피커 출력은 확인하지 못함).

## 10. 설치 경고 안내 (글에 넣을 문구)

서명이 없는 프로그램이라 처음 실행할 때 윈도우가 경고할 수 있습니다(디지털 서명 없음 확인됨 — `NotSigned`).

1. 「Windows의 PC 보호」 창이 뜨면 **「추가 정보」** 를 누릅니다.
2. 아래에 나타나는 **「실행」** 을 누릅니다.
3. 크롬에서 「흔히 다운로드되지 않는 파일」이라고 나오면 **「유지」** 를 선택합니다.

(이 경고는 일반적으로 알려진 동작이며, 직접 웹에서 받아 확인한 것은 아닙니다.)
