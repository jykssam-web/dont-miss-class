## 본문 (이미지 6장 첨부)

```
1교시 수업이 바뀐 걸 모르고 교무실에 앉아 있었던 적이 있어요.

그래서 내 수업이 시작되는 시각에 화면에 크게 알려 주는 프로그램을 만들었습니다. 이름은 「놓치지마수업」이고 무료예요.

컴시간알리미를 쓰는 학교, 윈도우 컴퓨터에서 쓸 수 있어요. 자세한 건 사진과 댓글에 적었습니다.
```

## 댓글 1

```
수업 시작 시각이 되면 이런 알림 창이 떠요. 화면 아무 곳이나 누르면 닫혀요.

교체·보강으로 바뀐 수업에는 「바뀐 수업」 표시가 붙어요. 소리와 글씨체는 고를 수 있어요.
```

## 댓글 2

```

시간표는 컴시간알리미에서 가져와서 내 수업만 골라 줘요. 이름이 같은 선생님이 있으면 어느 분인지 물어봐요. 마지막 「완료」를 누르면 저장돼요.
```

1315처럼 숫자만 쳐도 13:15로 바뀌어요.

## 올리기 전에 확인할 것

1. **첫 문장(계기)**: 「1교시 수업이 바뀐 걸 모르고 교무실에 있었다」는 정쌤이 티룸 수업 알림을 만들 때 하신 말씀입니다.
   공개해도 되는 이야기인지 확인하세요. 곤란하면 첫 문장을 「수업이 바뀐 걸 늦게 안 적이 있어요」로 바꾸면 됩니다.
2. **[링크]** 는 홈페이지 다운로드 글이 올라간 뒤에 채웁니다. 링크는 댓글에 두었습니다(본문 도달에 불리하지 않을 거라는 제 판단이며, 확인된 사실은 아닙니다).
3. **카드 3번의 이름·수업(정미지, 과학 1-1 등)은 설명용 예시**입니다. 카드 아래에 「설명용 예시예요」라고 적어 두었습니다.
4. 설치 파일을 **실제로 설치해 본 적이 없습니다.** 올리기 전에 한 번 설치해서 설치·첫 설정·알림이 뜨는 것까지 확인하세요.
5. 파란 경고창 안내는 일반적으로 알려진 동작입니다. 직접 웹에서 받아 확인한 것은 아닙니다.
6. 후기·이용자 수 같은 숫자는 쓰지 않았습니다. 없는 것을 만들지 마세요.
