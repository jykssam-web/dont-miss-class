## 댓글 1

```

시간표는 컴시간알리미에서 가져와서 내 수업만 골라요. 같은 이름의 선생님이 있으면 어느 분인지 물어보고요.
```

## 올리기 전에 확인할 것

1. **첫 문장(1교시 수업이 바뀐 걸 모르고 교무실에 앉아 있었다)**: 정쌤이 티룸 수업 알림을 만들 때 하신 말씀입니다.
   공개해도 되는지 확인하세요. 곤란하면 「수업이 바뀐 걸 늦게 안 적이 있어요」로 바꾸면 됩니다.
   둘째 문장(시간표는 내가 열어 봐야 보이니까요)도 같은 때 정쌤이 하신 생각을 풀어 쓴 것입니다.
2. **[링크]** 는 홈페이지 다운로드 글이 올라간 뒤에 채웁니다.
3. 카드 3번의 이름·수업(정미지, 과학 1-1 등)은 설명용 예시입니다.
4. 설치 파일을 실제로 설치해 본 적이 없습니다. 올리기 전에 한 번 설치해서 알림이 뜨는지 확인하세요.
5. 파란 경고창 안내는 일반적으로 알려진 동작이며, 직접 웹에서 받아 확인한 것은 아닙니다.
6. 후기·이용자 수 같은 숫자는 쓰지 않았습니다.
7. 첫 이미지(`1_cover.png`)의 큰 글은 아직 예전 문구(「내 수업 시작 시각에 화면에 크게 알려 줘요」)입니다.
